## 基础命令

以下是我日常使用最频繁的 Git 命令：

```bash
# 查看状态
git status

# 查看提交历史
git log --oneline --graph --all

# 查看差异
git diff
git diff --staged
```

## 分支管理

```bash
# 创建并切换分支
git checkout -b feature/new-feature

# 查看所有分支
git branch -a

# 删除本地分支
git branch -d feature/old-feature

# 删除远程分支
git push origin --delete feature/old-feature
```

## 暂存与回退

> Git 最强大的地方之一就是它允许你安全地"后悔"。几乎所有操作都可以撤销。

### 撤销工作区修改

```bash
# 撤销单个文件
git checkout -- filename

# 撤销所有修改
git checkout .
```

### 撤销暂存区

```bash
# 取消暂存
git reset HEAD filename

# 修改最后一次提交
git commit --amend
```

## 合并与变基

```bash
# 合并分支
git merge feature/new-feature

# 变基（rebase）
git rebase main

# 交互式变基（合并多个提交）
git rebase -i HEAD~3
```

| 操作 | 命令 | 说明 |
|------|------|------|
| 暂存 | `git stash` | 临时保存修改 |
| 恢复 | `git stash pop` | 恢复最近一次暂存 |
| 标签 | `git tag v1.0.0` | 创建轻量标签 |
| 推送标签 | `git push --tags` | 推送所有标签 |
| 日志搜索 | `git log -S"keyword"` | 搜索提交内容 |
| 二分查找 | `git bisect` | 定位引入 bug 的提交 |

## 远程操作

```bash
# 添加远程仓库
git remote add origin <url>

# 推送并设置上游
git push -u origin main

# 拉取并变基
git pull --rebase

# 强制推送（谨慎使用）
git push --force-with-lease
```

记住：**`--force-with-lease` 比 `--force` 更安全**，它会检查远程是否有你不知道的新提交。

## 实用技巧

### 修改作者信息

```bash
git commit --amend --author="JiGuro <jiguro@example.com>"
```

### 清理无用分支

```bash
# 删除已合并的本地分支
git branch --merged | grep -v "\*" | xargs -n 1 git branch -d
```

这些命令涵盖了日常工作 90% 的 Git 操作场景。收藏起来，随时查阅。
