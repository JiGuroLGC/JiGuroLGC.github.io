# 你好，世界

欢迎来到我的博客！这是我的第一篇文章。

其实很早就想搭一个属于自己的小站了。以前总是把想法、笔记随手丢在备忘录或者草稿箱里，时间一长就再也找不到了。后来觉得，不如干脆整理出来，放在一个自己完全掌控的地方。于是就有了 JiGuro's Blog。

## 关于我

我是一个热爱技术和生活的开发者。

要说 "热爱技术" 这件事，大概是从小学那会儿开始的。
梦想起步于营销号的一个视频，我从 Windows 开始学起，到手搓电脑病毒；从 Android 刷机到 Linux ；从前端到后端；从 Batch、VBS、Html 到 Python、Java、C ；从逆向到网络安全；从一个连电脑都不会用的小白，成长为今天的我。

那时候捣鼓的代码连 "Hello World" 都打不出来，盯着报错信息看了半天也没看懂。后来慢慢发现，编程这件事最迷人的地方不在于写出完美的代码，而在于你永远会遇到新问题，然后花一个下午把它解决掉的那种满足感。

生活中我也是个比较随性的人。喜欢半夜听歌，喜欢翻一些冷门的技术文章，偶尔也会被一个 bug 折磨到凌晨三点然后第二天顶着黑眼圈开始新的一天。这些都是挺真实的日常。

## 这个博客会写什么

目前没有什么宏大的计划。大概就是：

- 平时踩过的坑，记录一下省的以后再踩一次
- 学到的新东西，趁热打铁整理成笔记
- 偶尔写点碎碎念，就当自言自语
- 展示我的 “文学成就” 和摄影作品

不追求固定的更新频率，也不追求多高的浏览量。能帮到偶然路过的你当然最好，帮不到的话，至少算是我自己的一份存档。

## 技术栈

- **前端**: HTML, CSS, JavaScript
- **工具**: Git, Markdown
- **部署**: GitHub，Vercel，Cloudflare

整套站点的搭建思路很简单：尽量少依赖，尽量轻量。Hexo 生成静态页面，自己写了一点 CSS 和 JS 来做样式和交互，部署在 GitHub 上，然后再白嫖一个 Vercel 服务给文件加速、蹭一蹭赛博活佛 Cloudflare ，连服务器都不用管。虽然看起来朴素，但自己一步一步建起来的，用着踏实。
为了省钱，随便挑了个姨妈域名，能用就行，主要也是做 BetterVia 的分流 CDN ，所以也没太考虑，总计花费 5 RMB。

## 代码示例

```javascript
console.log('Hello, World!');
```

上面的这行代码大概是最经典的开场白了。每个程序员的第一行代码几乎都是它。当时觉得「就这？」，后来才明白，能顺利打印出一句话，背后其实已经跑了编译、解释、运行一整套流程。有时候简单的东西也挺值得琢磨的。像这个博客一样，页面干干净净，但该有的功能一个不少。

## 结语

即使翅膀断了，心也要飞翔。

开博客这件事想了很久，一直拖到今天才动手。果然很多事情缺的不是能力，就是那么一点迈出第一步的勇气。写到这里，第一篇算是正式完成了。希望未来的自己能坚持写下去，也希望这个小小的角落，能记录下一段还算精彩的旅程。

至于文章质量嘛 —— 先写出来再说，烂一点也没关系。  
同志，面包会有的，牛奶会有的，一切都会有的。

> 保持热爱，奔赴山海。
