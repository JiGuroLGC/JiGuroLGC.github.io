## 编辑器选择

我使用的是 Visual Studio Code，配合以下插件：

- **Vim** — 键盘操作效率神器
- **Prettier** — 代码格式化
- **ESLint** — JavaScript/TypeScript 代码检查
- **GitLens** — Git 增强功能

## 终端配置

我使用 [Warp](https://www.warp.dev/) 作为主力终端，它基于 Rust 构建，速度飞快。配合 Zsh 和以下配置：

```bash
# .zshrc 常用别名
alias g="git"
alias gs="git status"
alias gc="git commit"
alias gp="git push"
alias ll="ls -la"
alias ..="cd .."

# 启动时自动激活 conda 环境
if [ -f ~/miniconda3/etc/profile.d/conda.sh ]; then
    source ~/miniconda3/etc/profile.d/conda.sh
fi
```

## Node.js 环境

使用 `nvm` 管理 Node.js 版本：

```bash
# 安装 LTS 版本
nvm install --lts

# 安装最新版本
nvm install node

# 切换版本
nvm use 20
```

## 字体推荐

编程字体建议使用等宽字体：

> Cascadia Code 是微软推出的一款优秀编程字体，支持连字（ligatures），特别适合前端开发。

我个人推荐以下字体：

| 字体 | 特点 | 适用场景 |
|------|------|----------|
| Cascadia Code | 连字支持好 | VS Code |
| Fira Code | 经典等宽 | 通用 |
| JetBrains Mono | 清晰易读 | JetBrains IDE |
| Source Code Pro | Adobe 出品 | 长时间阅读 |

## Docker 环境

对于容器化开发，Docker 是必不可少的工具。常用的开发容器配置：

```yaml
# docker-compose.yml
version: '3.8'
services:
  app:
    build: .
    ports:
      - "3000:3000"
    volumes:
      - .:/app
    environment:
      - NODE_ENV=development
```

一个好的开发环境能极大提升工作效率。花时间配置好工具，是对自己的一种投资。
