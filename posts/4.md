转眼间，2024 年即将结束。这一年发生了很多事情，让我慢慢回顾。

## 技术成长

今年是我技术能力提升最快的一年。从年初开始系统学习前端工程化，到年底能够独立完成全栈项目，每一步都很有意义。

### 掌握的新技能

1. TypeScript 深入理解
2. React 生态（Next.js、Zustand、TanStack Query）
3. Node.js 后端开发
4. Docker 容器化部署
5. CI/CD 流水线搭建

### 完成的重点项目

- **个人博客系统**：从零搭建，使用 Hexo 生成静态站点
- **REST API 服务**：基于 Express + TypeScript 的后端服务
- **小程序开发**：一个社区团购工具
