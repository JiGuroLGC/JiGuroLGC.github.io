## 什么是 Markdown

Markdown 是一种轻量级标记语言，由 John Gruber 于 2004 年创建。它允许人们使用易读易写的纯文本格式编写文档，然后转换成有效的 HTML 文档。

## 为什么使用 Markdown

- **纯文本**：可以使用任何文本编辑器打开和编辑
- **易读**：即使不渲染，原始文本也很容易阅读
- **跨平台**：不依赖于特定的软件或操作系统
- **版本控制友好**：纯文本文件非常适合 Git 等版本控制系统

## 基本语法

### 标题

使用 `#` 号标记标题，支持六级标题：

# 一级标题
## 二级标题
### 三级标题

### 强调

使用 `*` 或 `_` 包裹文字来表示强调：

- *斜体* 使用单星号
- **粗体** 使用双星号
- ~~删除线~~ 使用波浪线

### 列表

无序列表：

- 项目一
- 项目二
  - 嵌套项目
  - 另一个嵌套

有序列表：

1. 第一步
2. 第二步
3. 第三步

### 链接与图片

链接格式：`[文本](URL)`

图片格式：`![替代文本](URL)`

### 代码

行内代码使用反引号：`console.log("Hello")`

## 扩展语法

许多 Markdown 解析器还支持扩展语法，包括：

> Markdown 的本质是让写作回归内容本身，而不是被格式所困扰。它是一种思维工具，让你专注于表达。

| 功能 | 标准 Markdown | 扩展语法 |
|------|--------------|----------|
| 表格 | 不支持 | 支持 |
| 代码块 | 缩进 | 围栏式 |
| 脚注 | 不支持 | 支持 |
| 任务列表 | 不支持 | 支持 |

## 总结

Markdown 已经成为技术写作的事实标准。无论是在 GitHub 上写 README，还是在博客中发表文章，掌握 Markdown 都是一项必备技能。
