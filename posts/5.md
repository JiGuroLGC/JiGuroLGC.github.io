## 博客搭建动机

我一直想要一个完全属于自己的写作空间。虽然有很多现成的平台（如知乎、掘金、Medium），但它们都有各自的限制：

- 平台规则随时可能变化
- 数据不属于自己
- 样式和排版受限于平台
- 无法自由定制功能

> 拥有自己的博客，就像拥有一个属于自己的房子。你可以按照自己的喜好装修，不受房东的限制。

## 技术选型

经过调研，我选择了以下技术栈：

### Hexo

Hexo 是一个快速、简洁且高效的博客框架。它使用 Markdown 解析文章，通过主题生成静态页面。

```bash
# 安装 Hexo
npm install -g hexo-cli

# 初始化博客
hexo init my-blog
cd my-blog
npm install

# 启动本地服务器
hexo server
```

### 静态托管

生成的静态文件托管在 GitHub Pages 上，完全免费：

```yaml
# GitHub Actions 自动部署配置
name: Deploy
on:
  push:
    branches: [main]
jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - uses: actions/setup-node@v3
      - run: npm ci
      - run: npm run build
      - uses: peaceiris/actions-gh-pages@v3
        with:
          github_token: ${{ secrets.GITHUB_TOKEN }}
          publish_dir: ./public
```

## 主题定制

我基于默认主题进行了大量自定义：

| 功能 | 实现方式 |
|------|----------|
| 暗色模式 | CSS 变量 + localStorage |
| 滚动浮现动画 | IntersectionObserver + CSS transition |
| 代码高亮 | Prism.js |
| 响应式布局 | CSS Grid + Flexbox |

## 遇到的坑

搭建过程中也遇到了一些问题：

1. **GitHub Pages 部署 404**：需要确认仓库设置中的 Pages 分支配置正确
2. **自定义域名 HTTPS**：需要等待证书自动签发，通常需要几分钟到几小时
3. **暗色模式闪烁**：通过在 `<head>` 中提前读取 localStorage 解决

## 总结

搭建博客的过程本身就是一个很好的学习项目。从域名注册、DNS 配置、CI/CD 部署，到前端动画优化，每一个环节都能学到新东西。

如果你也想搭建自己的博客，希望这篇文章能给你一些启发。最重要的是 —— **开始做，而不是一直想**。
