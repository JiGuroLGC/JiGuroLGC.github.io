本文档记录了博客中所有支持的 Markdown 语法和自定义扩展语法。


一、图片语法（核心自定义）

--------------------------------------------------------------------------------
1.1  基础图片（自动灯箱）

  <img src="图片URL" alt="图片标题">

  - 不设置 width / height 时，图片会自动包裹为灯箱卡片 (.ps-figure)。
  - alt 文本将显示为卡片底部黑色渐变条中的标题。
  - 点击图片打开 Fancybox 灯箱，同一篇文章的图片在同一组中互相切换。

--------------------------------------------------------------------------------
1.2  带 EXIF / 参数信息

  <img src="图片URL" alt="图片标题" data-exif="23mm · f/2.8 · 1/250s · ISO 100">

  data-exif 属性提供拍摄参数或额外元信息。
  - 卡片底部：标题始终显示，EXIF 悬停时展开（桌面）或长按时展开（移动端）。
  - 灯箱内：标题和 EXIF 并排显示在底部信息栏。

--------------------------------------------------------------------------------
1.3  自定义宽高比（防止布局抖动）

  <img src="图片URL" alt="标题" data-ratio="4:3">

  支持的比例格式：如 "16:9"、"4:3"、"3:2"、"1:1" 等。
  未指定时默认使用 16:9 作为占位比例，图片加载完成后自动修正为实际比例。

  桌面端（≥1024px）：竖图（自然高度超过 80vh）会自动约束宽度，
  卡片居中显示，避免因 max-height 限制留下两侧大块空隙。

--------------------------------------------------------------------------------
1.4  徽章 / 内联图标（不参与灯箱）

  <img src="图标URL" width="32" height="32" data-badge>
  <img src="https://img.shields.io/..." height="20" data-badge>

  data-badge 属性将图片标记为徽章或内联图标：
  - 包裹为 .img-placeholder（灰色背景 + 圆角），不参与灯箱
  - 加载完成后占位背景透明化、圆角去除，与正常图片表现一致
  - 保留 width/height 指定的显式尺寸
  - 仅应用渐进式模糊-清晰加载

  注意：不带 data-badge 但有 width/height 的图片（如 socialify 卡片、
  截图等）现在也会包裹为 ps-figure 灯箱卡片。请务必给所有徽章加 data-badge。

--------------------------------------------------------------------------------
1.5  链接图片

  <a href="链接URL"><img src="图片URL" alt="描述"></a>

  被 <a> 包裹的图片会在渲染时从链接中移出，然后包裹为 .ps-figure 灯箱卡片。
  这意味着链接图片现在也支持点击放大和 Fancybox 浏览。

  如需保留跳转行为（而非灯箱），请在 img 上添加 data-badge 属性。

--------------------------------------------------------------------------------
1.6  加载失败提示

  图片加载失败时，卡片中央显示圆形感叹号图标和"图片加载失败"文字，
  保留占位背景，移除卡片圆角和阴影。

--------------------------------------------------------------------------------
1.7  加载完成后的表现

  图片加载完成后：
  - 占位背景平滑过渡为透明
  - 卡片圆角（border-radius）和暗色模式边界线（box-shadow）去除
  - 图片与页面底色自然融合，无视觉分割


二、Obsidian Callout（标注框）

--------------------------------------------------------------------------------
2.1  基本语法

  > [!类型] 标题文本
  > 正文内容

  支持的 callout 类型：
  - note      蓝色/i 图标，通用笔记
  - info      蓝色/i 图标，信息提示
  - tip       绿色/✓ 图标，技巧建议
  - warning   橙色/! 图标，注意事项
  - danger    红色/! 图标，严重警告
  - example   紫色/● 图标，示例演示
  - quote     灰色/" 图标，引用语录

三、标准 Markdown 语法

--------------------------------------------------------------------------------
3.1  标题

  # 一级标题
  ## 二级标题
  ### 三级标题
  #### 四级标题

--------------------------------------------------------------------------------
3.2  文本样式

  **粗体文本**
  *斜体文本*
  ~~删除线~~
  `行内代码`

--------------------------------------------------------------------------------
3.3  引用

  > 引用文本
  > 可以多行

--------------------------------------------------------------------------------
3.4  列表

  无序列表：
  - 项目一
  - 项目二
    - 子项目

  有序列表：
  1. 第一步
  2. 第二步

--------------------------------------------------------------------------------
3.5  代码块（语法高亮）

  ```语言名
  代码内容
  ```

  示例：
  ```javascript
  console.log('Hello World');
  ```

  ```python
  def hello():
      print('Hello World')
  ```

  ```smali
  .method public static main([Ljava/lang/String;)V
      .registers 3
      const-string v0, "Hello"
      return-void
  .end method
  ```

  语言名支持 highlight.js 原生语言以及自定义注册的 smali 语言。

--------------------------------------------------------------------------------
3.6  链接和图片

  [链接文本](https://example.com)
  ![图片替代文本](https://example.com/image.jpg)

--------------------------------------------------------------------------------
3.7  分割线

  ---

--------------------------------------------------------------------------------
3.8  表格

  | 列1 | 列2 | 列3 |
  |-----|-----|-----|
  | A   | B   | C   |
  | D   | E   | F   |

--------------------------------------------------------------------------------
3.9  上标脚注

  <sup>[1]</sup> 参考内容

  例如：
  莫听穿林打叶声<sup>[1]</sup>

  [1] 大雨点透过树林打在树叶上的声音。


四、文章元数据（index.json）

--------------------------------------------------------------------------------
每篇文章在 /posts/index.json 中定义元数据：

  {
      "id":          "2024-07-27",              // 文章唯一 ID（通常为文件名）
      "title":       "文章标题",                  // 页面标题
      "description": "文章摘要描述",              // SEO 和列表展示
      "author":      "JiGuro",                  // 作者名
      "date":        "2024-07-27",              // 发布日期 (YYYY-MM-DD)
      "time":        "19:16:08",                // 发布时间
      "image":       "https://...封面图.jpg",     // 封面图 URL
      "tags":        ["标签1", "标签2"],          // 标签数组
      "category":    "分类名",                   // 分类名称
      "path":        "posts/2024-07-27.md",     // Markdown 文件路径
      "toc":         true                       // （可选）是否生成文章目录
  }

  - image 字段为空时，文章不显示封面图。
  - category 字段影响"返回文章列表"的链接目标。
  - path 支持本地相对路径和 CDN 绝对路径。
  - toc 为 true 时，文章正文前自动生成目录，支持点击跳转和闪烁动画。


五、自动功能（无需额外语法）

--------------------------------------------------------------------------------
5.1  渐进式图片加载
  所有图片加载完成后从模糊到清晰过渡，无需配置。

5.2  滚动渐显动画
  页面内容元素进入视口时自动淡入上移，基于 IntersectionObserver。

5.3  代码语法高亮
  代码块自动使用 highlight.js 执行语法高亮，主题随亮/暗模式切换。

5.4  灯箱图片分组
  同一篇文章的所有图片自动归入同一组，点击后可通过箭头或滑动切换。
  封面图（post-cover）不参与灯箱。

5.5  中英文间距
  自动渲染处理，无需额外标记。

5.6  文章目录（TOC）
  在 index.json 的元数据中设置 "toc": true 即可启用。
  文章中的 h2/h3/h4 标题自动生成目录，支持折叠/展开，
  点击目录条目平滑滚动到对应标题并触发闪烁高亮动画。


六、完整图片示例

--------------------------------------------------------------------------------
  <!-- 基础图片：仅标题 -->
  <img src="https://cdn.example.com/photo.jpg" alt="落日余晖">

  <!-- 完整图片：标题 + EXIF + 宽高比 -->
  <img src="https://cdn.example.com/photo.jpg"
       alt="落日余晖"
       data-exif="23mm · f/2.8 · 1/250s · ISO 100"
       data-ratio="3:2">

  <!-- 徽章/内联图标：使用 data-badge，不参与灯箱 -->
  <img src="https://img.shields.io/github/stars/repo" alt="" height="20" data-badge>
  <img src="https://cdn.example.com/badge.png" alt="" width="24" height="24" data-badge>

  <!-- 链接图片：会被移出 <a> 并包裹为灯箱卡片 -->
  <a href="https://github.com">
    <img src="https://cdn.example.com/github.png" alt="GitHub">
  </a>

  <!-- 纯 Markdown 格式（同样有效） -->
  ![落日余晖](https://cdn.example.com/photo.jpg)
